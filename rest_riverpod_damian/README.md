# rest_riverpod_damian

Flutter + Riverpod app: Home screen -> Todo List fetched from
https://jsonplaceholder.typicode.com/todos (completed items struck through, with checkbox).

## Setup (run from the main git-connected mobile app folder)
    flutter create rest_riverpod_damian
    # copy this project's lib/, test/, pubspec.yaml, README.md over the generated ones
    cd rest_riverpod_damian
    flutter pub get
    flutter run -d chrome
